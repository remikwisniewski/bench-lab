    System summary

    Everything this browser will say about your machine. Browsers hide some details, like the CPU model, on purpose.

    Hardware guess

    Browsers hide the CPU model, so Bench Lab works it out. It times memory reads at growing sizes to find the cache sizes, runs work on more and more threads to count real cores, and matches the results against the specifications of real CPUs.

    Takes about 15 seconds. Close other heavy apps for the best guess.

    Sensors

    Live readings, once a second. A web page can't read temperatures, clocks or voltages, so these are things it can measure: render speed per thread, a CPU speed probe, frame rate, lag, memory, network and battery.
